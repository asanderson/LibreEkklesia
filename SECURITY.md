# Security policy

## Report a vulnerability

Report security problems privately through GitHub: on the repository's **Security** tab, choose **Report a vulnerability**, or go straight to https://github.com/asanderson/LibreEkklesia/security/advisories/new. Public issues and pull requests are for everything else.

A useful report gives the affected commit or release, the steps to reproduce, and what an attacker could do.

## What happens next

- We acknowledge the report within 7 days.
- We agree a fix and a disclosure date with you. Disclosure happens within 90 days of the report, sooner when a problem is being exploited.
- The published advisory credits you, unless you ask to stay anonymous.

## Scope

- **In scope:** the code in this repository and the release images it publishes.
- **Out of scope:** live installations run by churches. Test against an install of your own, touch only data that is yours, and leave out denial-of-service testing.

## Supported versions

LibreEkklesia has no release yet. Once releases begin, the latest release receives security fixes.
