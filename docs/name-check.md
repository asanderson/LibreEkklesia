# LibreEkklesia name check

**Date:** 24 November 2026.
**Type:** quick web screen by Claude. This is not legal clearance. A trademark attorney should clear the name before public launch, before a legal entity is formed, and before any fee is charged.
**Status:** decided on 25 November 2026. The owner kept the name (option a below).

Source of truth: the `docs/` folder of https://github.com/asanderson/LibreEkklesia. Copies elsewhere, such as the claude.ai project, may lag behind.

## Summary

- The exact name "LibreEkklesia" turned up no existing use.
- The domains and account names checked appear to be free.
- Main risk: "Ekklesia" is a crowded name in church software, and one live US registration sits in the same market: Ekklesia 360, a church website platform.

Notes for an attorney:

- USPTO records translate "ekklesia" as "church" (for example in the E EKKLESIA360 record) and list "Ecclesia" spellings as equivalents.
- Some church-related filings disclaim the word "ECCLESIA" (for example MYSTIC ROSE OF THE ECCLESIA and ECCLESIA IN DIACONIA).

## Products and projects with close names

- **Ekklesia 360:** church website CMS, founded 2006. One company profile names Monk Development as parent, and Ministry Brands lists it on its own site. ekklesia360.com has been registered since 2006 through MarkMonitor.
- **Ekklesia:** open-source headless CMS for churches in Francophone Africa.
- **Ekklesia Church OS:** church management app with giving.
- **Ekklesia** by grassr-solutions: church management platform.
- **ekklesia-record:** small church management project on GitHub (Liberia).
- **Ecclesia:** church management app (membership, accounting, events). **Eklesia:** Portuguese-language church app.
- **Not church software:** Ekklesia, an open-source e-democracy platform; ekklesia.gr, a Greek direct-democracy app; Ekklesia, a former UK Christian think tank.
- **LibreChurch:** project of the German nonprofit LUKi e.V., hosting free software services for churches.
- **EcclesiaCRM:** self-hosted church CRM, code on GitHub.

## Decision

Options put to the owner on 24 November 2026:

- **(a) Keep the name.** Register both domains and a GitHub organization now, and get an attorney screen before drop 1 goes public.
- **(b) Rename now,** while nothing is public, then rerun this check on a shortlist.

Claude recommended (b). On 25 November 2026 the owner chose **(a), keep the name**, with development in the owner's personal repository, https://github.com/asanderson/LibreEkklesia, in place of an organization. The other follow-ups from option (a) are tracked in `plan.md`: register libreekklesia.com and libreekklesia.org, and get a trademark attorney screen before drop 1 goes public.
