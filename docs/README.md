# LibreEkklesia docs

Decision records and plans for LibreEkklesia, a free and open source church management website. This folder is the source of truth; copies elsewhere may lag behind.

| Document | What it holds | Status |
|---|---|---|
| [`scope-decisions.md`](scope-decisions.md) | Guiding principles, foundations, security rules, MVP, roadmap and hosted option | Signed off 18 November 2026 |
| [`stack-decisions.md`](stack-decisions.md) | Technology stack, dependency policy, updates, backups, tests and scans | Signed off 23 November 2026 |
| [`plan.md`](plan.md) | Delivery phases from foundations to the later pool, with tasks and exit criteria | Draft for owner review |
| [`name-check.md`](name-check.md) | Trademark, domain and account screen for the name, and the decision to keep it | Decided 25 November 2026 |
| [`feature-catalog.md`](feature-catalog.md) | 396 features in 24 areas with stable IDs such as `GIV-04` | Reference |
| [`feature-landscape.md`](feature-landscape.md) | Research report on commercial and open source church software behind the catalog | Reference, 15 November 2026 |

## Which document wins

1. `scope-decisions.md` wins over everything else.
2. `stack-decisions.md` comes next.
3. `plan.md` follows both. A plan that contradicts them is wrong, not a new decision.

Changes to a signed-off decision need the owner's sign-off and a dated entry in that document.
